### Resumen Técnico del Archivo `Rag.py`
#### Responsabilidad Principal
El archivo `Rag.py` es el encargado de la "Memoria a Largo Plazo" de una IA, transformando documentos PDF estáticos en una base de datos semántica inteligente.

#### Secciones
##### 1. Introducción y Clases Auxiliares
- El archivo comienza con una introducción a su función y una descripción de cómo funciona en tres pasos: leer, trocear y vectorizar.
- Se define una clase `RecursiveChunker` para dividir el texto en fragmentos manejables.

##### 2. Función de Inicialización
- La función `inicializar_rag` es el punto de entrada principal.
- Comprueba si la base de datos vectorial ya existe y la carga si es así.
- De lo contrario, lee los PDFs proporcionados, los procesa y crea la base de datos desde cero.

##### 3. Función de Búsqueda
- La función `buscar_contexto` permite buscar información en la base de datos vectorial.
- Recibe una consulta y devuelve los párrafos más relacionados de los documentos indexados.

#### Funcionamiento
1. **Lectura de PDF**: Extrae el texto plano de los archivos PDF.
2. **Troceado (Chunking)**: Divide el texto en fragmentos pequeños para su procesamiento.
3. **Vectorización y Guardado**: Convierte los fragmentos en embeddings y los guarda en ChromaDB para permitir búsquedas semánticas.

#### Tecnologías Utilizadas
- `chromadb` para la base de datos vectorial.
- `pypdf` para la lectura de archivos PDF.
- `embedding_functions` de `chromadb` para la vectorización del texto.

#### Uso
- El archivo se utiliza llamando a la función `inicializar_rag` con una lista de rutas a archivos PDF.
- Posteriormente, se puede utilizar la función `buscar_contexto` para realizar búsquedas en la base de datos creada.

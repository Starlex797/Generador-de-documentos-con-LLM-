# Resumen Técnico del Archivo `ml_model.py`
## Introducción
El archivo `ml_model.py` es un script de Python diseñado para entrenar y utilizar un modelo de Machine Learning (ML) para predecir precios de viviendas. El modelo se entrena con un conjunto de datos específico y se utiliza para hacer predicciones basadas en características de las viviendas.

## Responsabilidad Principal
La responsabilidad principal de este archivo es entrenar un modelo de regresión de bosque aleatorio (`RandomForestRegressor`) con un conjunto de datos de precios de viviendas y proporcionar una función (`predecir_precio`) que permite predecir el precio de una vivienda basada en características como el número de dormitorios, metros cuadrados, distancia al centro, distancia al metro, piso y edad de la vivienda.

## Secciones
### Carga de Datos
- El script carga un conjunto de datos de Kaggle utilizando `kagglehub.dataset_download`.
- Los datos se almacenan en un DataFrame de Pandas (`df`) después de leer el archivo CSV correspondiente.

### Entrenamiento del Modelo
- Se separan las características (`X`) y el objetivo (`y`) del DataFrame.
- Se entrena un modelo de `RandomForestRegressor` con los datos, utilizando 100 árboles y un estado aleatorio fijo para la reproducibilidad.

### Función de Predicción
- La función `predecir_precio` toma como entrada varias características de una vivienda y crea un DataFrame con una sola fila para estas características.
- Utiliza el modelo entrenado para predecir el precio de la vivienda y devuelve el resultado redondeado a 2 decimales.

## Uso
Este script se utiliza en un contexto de chatbot o asistente de lenguaje natural para proporcionar predicciones de precios de viviendas basadas en características específicas. La función `predecir_precio` es la interfaz principal para interactuar con el modelo entrenado.

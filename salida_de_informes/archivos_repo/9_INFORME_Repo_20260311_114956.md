## Resumen Técnico del Archivo `mis_tools.py`
### Responsabilidad Principal
El archivo `mis_tools.py` define las herramientas disponibles para el modelo de lenguaje (LLM) y establece un contrato para la comunicación entre la IA y el código Python.

### Secciones
#### 1. Introducción
El archivo `mis_tools.py` es descrito como el "Manual de Instrucciones" o "Menú de Habilidades" que se entrega a la IA. Es fundamental que este archivo esté bien escrito y sea claro, ya que la IA no puede utilizar las herramientas correctamente si la descripción no es clara.

#### 2. Definición de Herramientas
El archivo define una lista de herramientas disponibles, cada una con un identificador único, descripción, parámetros y requisitos. Las herramientas definidas son:
* `consultar_pdf`: busca información técnica en la base de conocimientos (manuales, normativas y guías PDF).
* `predecir_precio_casa`: calculadora precisa de precios de viviendas.

#### 3. Contrato de Comunicación
El archivo establece un contrato para la comunicación entre la IA y el código Python. La IA debe enviar un mensaje con una instrucción técnica, que incluye una clave y un valor. El código Python recibe este mensaje, extrae el contenido y lo utiliza para realizar la acción correspondiente.

#### 4. Ejemplo de Funcionamiento
El archivo proporciona un ejemplo de cómo funciona la herramienta `consultar_pdf`. La IA envía un mensaje con la clave "busqueda" y el valor "normas de seguridad". El código Python recibe este mensaje, extrae el valor y lo utiliza para buscar información en la base de conocimientos.

### Conclusión
En resumen, el archivo `mis_tools.py` es fundamental para la comunicación entre la IA y el código Python. Define las herramientas disponibles y establece un contrato para la comunicación, lo que permite a la IA utilizar las herramientas correctamente y realizar acciones precisas.

## Resumen Técnico del Archivo Rag.py
### Responsabilidad Principal
El archivo `Rag.py` es el cerebro del sistema "Retrieval-Augmented Generation" (RAG), responsable de transformar documentos PDF estáticos en una base de datos semántica inteligente.

### Secciones
#### 1. Clases y Funciones Auxiliares
*   La clase `RecursiveChunker` se encarga de dividir el texto en fragmentos manejables y lógicos.
*   La función `cargar_pdf` extrae el texto plano de un archivo PDF.

#### 2. Función de Inicialización
*   La función `inicializar_rag` es el punto de entrada del sistema, que comprueba si la base de datos vectorial ya existe y la carga o crea desde cero.

#### 3. Función de Búsqueda
*   La función `buscar_contexto` encuentra los párrafos del PDF más relacionados con una pregunta del usuario y retorna un texto único con la información encontrada.

### Funcionamiento
El archivo `Rag.py` funciona en tres pasos:

1.  **LEER**: Extrae el texto plano del PDF utilizando la función `cargar_pdf`.
2.  **TROCEAR (Chunking)**: Divide el texto en fragmentos pequeños utilizando la clase `RecursiveChunker`.
3.  **VECTORIZAR Y GUARDAR**: Convierte los fragmentos en listas de números (embeddings) y los guarda en ChromaDB, permitiendo buscar información por significado y no solo por palabras clave.

### Uso
El archivo `Rag.py` se utiliza para inicializar el sistema RAG y realizar búsquedas en la base de datos semántica. La función `inicializar_rag` se llama con una lista de archivos PDF como argumento, y la función `buscar_contexto` se llama con una pregunta del usuario y la colección de documentos como argumentos.

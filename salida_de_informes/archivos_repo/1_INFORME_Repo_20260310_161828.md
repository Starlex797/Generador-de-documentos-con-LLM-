# Resumen Técnico del Archivo `app.py`
=====================================================

## Responsabilidad Principal
El archivo `app.py` es el punto de entrada de una aplicación que interactúa con un modelo de lenguaje grande (LLM) para responder preguntas y realizar tareas específicas. Su responsabilidad principal es cargar la configuración, inicializar el modelo y el RAG (Retrieve, Augment, Generate), y manejar el flujo de conversación con el usuario.

## Secciones del Archivo
El archivo se divide en varias secciones:

1. **Configuración**: La función `load_config()` carga la configuración desde variables de entorno y valida los parámetros.
2. **Funciones de Chat**: La función `chat_backend()` es una función unificada para interactuar con el LLM, ya sea Ollama o Groq.
3. **Bucle Principal**: La función `main()` es el punto de entrada de la aplicación, donde se carga la configuración, se inicializa el RAG y se maneja el flujo de conversación con el usuario.

## Funcionalidad
La aplicación utiliza el RAG para buscar información en documentos PDF y el LLM para responder preguntas y realizar tareas. La conversación se maneja a través de un bucle principal que:

1. Lee la entrada del usuario.
2. Verifica si la entrada es un comando (exit o reset).
3. Llama al LLM para obtener una respuesta.
4. Verifica si la respuesta del LLM incluye una llamada a una herramienta (RAG o ML).
5. Si es así, ejecuta la herramienta y agrega el resultado al historial de conversación.
6. Llama al LLM nuevamente con el historial actualizado para obtener una respuesta final.

## Herramientas Utilizadas
La aplicación utiliza las siguientes herramientas:

1. **RAG**: Retrieve, Augment, Generate, para buscar información en documentos PDF.
2. **ML**: Machine Learning, para predecir el precio de una casa.
3. **Ollama**: Un modelo de lenguaje grande para responder preguntas y realizar tareas.
4. **Groq**: Un modelo de lenguaje grande para responder preguntas y realizar tareas.

## Conclusión
El archivo `app.py` es una aplicación que interactúa con un modelo de lenguaje grande y herramientas específicas para responder preguntas y realizar tareas. Su funcionalidad se basa en la carga de configuración, la inicialización del RAG y el manejo del flujo de conversación con el usuario.

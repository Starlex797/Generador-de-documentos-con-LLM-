# Informe Técnico: fields.py
## Resumen General
El archivo `fields.py` contiene la implementación de los campos personalizados para el módulo `marshmallow`. Estos campos se utilizan para serializar y deserializar datos en formato JSON. El archivo define varias clases, incluyendo `Field`, `Raw`, `Nested` y `Pluck`, cada una con sus propios métodos y atributos.

## Arquitectura y Estructura
La arquitectura del archivo se basa en la definición de clases que heredan de `Field`. Cada clase tiene sus propios métodos y atributos que se utilizan para serializar y deserializar datos. Los métodos más importantes son `__init__`, `_serialize` y `_deserialize`, que se utilizan para inicializar los campos, serializar y deserializar datos, respectivamente.

*   `Field`: Clase base para todos los campos personalizados. Define los métodos `__init__`, `_serialize` y `_deserialize`, entre otros.
*   `Raw`: Clase que representa un campo raw. No tiene métodos adicionales.
*   `Nested`: Clase que representa un campo anidado. Define los métodos `__init__`, `_serialize` y `_deserialize`, entre otros.
*   `Pluck`: Clase que representa un campo que extrae un valor de un campo anidado. Define los métodos `__init__` y `_field_data_key`, entre otros.
*   `List`: Clase que representa un campo que contiene una lista de valores. Define los métodos `__init__`, `_bind_to_schema`, `_serialize` y `_deserialize`, entre otros.
*   `Tuple`: Clase que representa un campo que contiene una tupla de valores. Define los métodos `__init__`, `_bind_to_schema`, `_serialize` y `_deserialize`, entre otros.
*   `String`: Clase que representa un campo que contiene una cadena de texto. Define los métodos `_serialize` y `_deserialize`, entre otros.
*   `UUID`: Clase que representa un campo que contiene un identificador único universal. Define los métodos `_validated` y `_deserialize`, entre otros.
*   `Number`: Clase base para los campos numéricos. Define los métodos `__init__`, `_format_num`, `_validated`, `_to_string`, `_serialize` y `_deserialize`, entre otros.
*   `Integer`: Clase que representa un campo que contiene un número entero. Define los métodos `__init__` y `_validated`, entre otros.
*   `Float`: Clase que representa un campo que contiene un número flotante. Define los métodos `__init__` y `_validated`, entre otros.
*   `Decimal`: Clase que representa un campo que contiene un número decimal. Define los métodos `__init__`, `_format_num`, `_validated`, `_to_string`, entre otros.

### Ejemplo de Uso
A continuación, se muestra un ejemplo de uso de la clase `Field`:
```python
from marshmallow import Schema, fields

class UsuarioSchema(Schema):
    nombre = fields.Str()
    edad = fields.Int()

class DireccionSchema(Schema):
    calle = fields.Str()
    ciudad = fields.Str()

class UsuarioConDireccionSchema(Schema):
    usuario = fields.Nested(UsuarioSchema)
    direccion = fields.Nested(DireccionSchema)

# Crear un esquema
schema = UsuarioConDireccionSchema()

# Serializar un objeto
usuario = {'nombre': 'Juan', 'edad': 30}
direccion = {'calle': 'Calle 1', 'ciudad': 'Ciudad 1'}
obj = {'usuario': usuario, 'direccion': direccion}
result = schema.dump(obj)

# Deserializar un objeto
data = {'usuario': {'nombre': 'Juan', 'edad': 30}, 'direccion': {'calle': 'Calle 1', 'ciudad': 'Ciudad 1'}}
result = schema.load(data)
```
En este ejemplo, se define un esquema `UsuarioConDireccionSchema` que contiene dos campos anidados: `usuario` y `direccion`. Luego, se crea un objeto que se serializa y deserializa utilizando el esquema.

```python
    ret = super()._serialize(nested_obj, attr, obj, **kwargs)
    if ret is None:
        return None
    if self.many:
        return utils.pluck(ret, key=self._field_data_key)
    return ret[self._field_data_key]
```

```python
def _deserialize(self, value, attr, data, **kwargs) -> list[typing.Any]:
    if not utils.is_collection(value):
        raise self.make_error('invalid')
    result = []
    errors = {}
    for idx, each in enumerate(value):
        try:
            result.append(self.inner.deserialize(each, **kwargs))
        except ValidationError as error:
            if error.valid_data is not None:
                result.append(error.valid_data)
            errors.update({idx: error.messages})
    if errors:
        raise ValidationError(errors, valid_data=result)
    return result
```

```python
def __init__(self, tuple_fields: typing.Iterable[Field] | typing.Iterable[type[Field]], **kwargs):
    super().__init__(**kwargs)
    if not utils.is_collection(tuple_fields):
        raise ValueError('tuple_fields must be an iterable of Field classes or instances.')
    try:
        self.tuple_fields = [resolve_field_instance(cls_or_instance) for cls_or_instance in tuple_fields]
    except FieldInstanceResolutionError as error:
        raise ValueError('Elements of "tuple_fields" must be subclasses or instances of marshmallow.base.FieldABC.') from error
    self.validate_length = Length(equal=len(self.tuple_fields))
```

```python
    for field in self.tuple_fields:
```

```python
def _deserialize(self, value, attr, data, **kwargs) -> tuple:
    if not utils.is_collection(value):
        raise self.make_error('invalid')
    self.validate_length(value)
    result = []
    errors = {}
    for idx, (field, each) in enumerate(zip(self.tuple_fields, value)):
        try:
            result.append(field.deserialize(each, **kwargs))
        except ValidationError as error:
            if error.valid_data is not None:
                result.append(error.valid_data)
            errors.update({idx: error.messages})
    if errors:
        raise ValidationError(errors, valid_data=result)
    return tuple(result)
```

### Clase UUID - Método: _validated
```python
def _validated(self, value) -> uuid.UUID | None:
    """Format the value or raise a :exc:`ValidationError` if an error occurs."""
    if value is None:
        return None
    if isinstance(value, uuid.UUID):
        return value
    try:
        if isinstance(value, bytes) and len(value) == 16:
            return uuid.UUID(bytes=value)
        return uuid.UUID(value)
    except (ValueError, AttributeError, TypeError) as error:
        raise self.make_error('invalid_uuid') from error
```

```python
def _validated(self, value: typing.Any) -> _NumType:
    """Format the value or raise a :exc:`ValidationError` if an error occurs."""
    if value is True or value is False:
        raise self.make_error('invalid', input=value)
    try:
        return self._format_num(value)
    except (TypeError, ValueError) as error:
        raise self.make_error('invalid', input=value) from error
    except OverflowError as error:
        raise self.make_error('too_large', input=value) from error
```
